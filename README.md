# Project Setup

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Prerequisites

- Node.js (LTS recommended)
- npm

## Run Locally

```sh
npm install
npm run dev
```

Default dev URL is usually:

```text
http://localhost:8080
```

## Build

```sh
npm run build
```

## Preview Production Build

```sh
npm run preview
```

## Lint

```sh
npm run lint
```

## Test

```sh
npm run test
```
